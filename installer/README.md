# Instalador del parche (GalaxyzNeoES)

Aplicación Tauri 2 (Svelte + Rust) que instala, actualiza y desinstala el parche en español.

Toda la documentación (arquitectura, cómo publicar versiones, cómo añadir imágenes traducidas y cómo
probar) está en [`docs/INSTALADOR.md`](../docs/INSTALADOR.md).

```bash
npm install
npm run tauri dev
```
