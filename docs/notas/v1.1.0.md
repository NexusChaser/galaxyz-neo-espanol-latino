# v1.1.0 — Instalador

La traducción es la misma que en la v1.0; esta versión añade un instalador fácil que detecta el juego, se actualiza solo y se desinstala desde Windows.

## Qué hay de nuevo

- **`GalaxyzNeoES.exe`, el instalador recomendado.**
  - Detecta GALAXYZ neo en Steam y la carpeta del parche, o deja elegirlas a mano.
  - Hace copia de seguridad solo si hace falta y deshace todo si algo falla.
  - **Actualización automática opcional** (cada 6 h, 12 h, una vez al día o semanal).
  - Reparar y desinstalar desde el menú Inicio o desde «Aplicaciones instaladas».
- **El ZIP con `instalar.bat` sigue disponible** para quien prefiera instalar con el `.bat` o a mano.

## Descargas

| Archivo | Para qué |
|---|---|
| `GalaxyzNeoES.exe` | **Recomendado.** Doble clic y seguir los pasos. |
| `GALAXYZ-neo-Espanol-Latino.zip` | Instalación con `instalar.bat` o manual. |
| `manifest.json` | Lo usa el instalador para buscar actualizaciones; no hace falta descargarlo. |

## Avisos

- ⚠️ La primera vez Windows puede mostrar **«Windows protegió tu PC»**, porque el programa no está firmado (es un proyecto de fans). Pulsa **Más información → Ejecutar de todas formas**.
- ⚠️ Es normal que el juego se cierre mientras carga la pantalla de inicio. Sigue abriéndolo hasta que entre.
- 🖼️ Los textos dentro de imágenes todavía no están traducidos.
